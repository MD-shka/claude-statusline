# Mocha Powerline

Статусная строка Claude Code в палитре Catppuccin Mocha. Сегменты слева направо:

```
 Opus 5 ▸ statusbar ▸ main ✗ ▸ 3.12.4 ▸ 󰾆 37% ▸  5h 12% · 7d 63% ▸  09:15
```

| сегмент | что показывает |
|---|---|
| модель | отображаемое имя текущей модели |
| каталог | имя рабочей папки |
| git | ветка и `✗`, если есть незакоммиченные изменения; скрыт вне репозитория |
| python | версия `python3`, только в python-проектах |
| контекст | процент занятого контекстного окна |
| **лимиты** | **расход подписки: `5h` — сессионное окно, `7d` — недельное; от 80% рядом появляется время до сброса (`↻2h`)** |
| время | часы и минуты |

## Установка

```sh
claude plugin marketplace add Madmadmax/claude-statusline
claude plugin install mocha-powerline@mocha-powerline
```

При старте следующей сессии `SessionStart`-хук пропишет строку в `~/.claude/settings.json`.
Подключить сразу, не дожидаясь перезапуска: `/mocha-powerline:enable`.

### Требования

- **jq** — строка парсит JSON, который Claude Code передаёт ей в stdin (`brew install jq`);
- **Nerd Font** в терминале — иначе вместо разделителей и иконок будут квадратики;
- **truecolor**-терминал: iTerm2, Ghostty, WezTerm, Kitty, Alacritty, Terminal.app в macOS 14+;
- **подписка Claude.ai** — только для сегмента лимитов, всё остальное работает всегда.

## Отключение

```
/mocha-powerline:disable          # убрать строку, плагин оставить
claude plugin disable mocha-powerline   # выключить плагин целиком
```

## Как это устроено

В манифесте плагина **нет** поля `statusLine` — Claude Code такого поля не знает и игнорирует
его при загрузке (`claude plugin validate` прямо об этом предупреждает). Статусная строка
задаётся только ключом `statusLine` в `settings.json`, поэтому плагин делает это сам:

- `hooks/wire-statusline.sh` — на `SessionStart` прописывает в `~/.claude/settings.json`
  абсолютный путь к `statusline.sh` (`${CLAUDE_PLUGIN_ROOT}` в самом `settings.json` не
  раскрывается, поэтому путь резолвится в момент подключения);
- если `statusLine` уже занят **чужой** строкой — скрипт её не трогает и говорит об этом;
- запись идемпотентная: если всё уже прописано, файл не переписывается;
- при битом `settings.json` или отсутствии `jq` скрипт молча выходит с кодом 0, не ломая старт сессии.

Остальные ключи `settings.json` не затрагиваются — правится только `.statusLine`.

## Настройка

Всё в одном файле `statusline.sh`:

- **порог для `↻`** — найти `-ge 80` (два места) и поставить своё число;
- **убрать сегмент** — удалить соответствующий блок `if` в конце файла; соседи состыкуются
  сами, цвет разделителя берётся из `last_bg`;
- **светлая палитра (Catppuccin Latte)** — заменить блок цветов в формате `R;G;B`:
  `crust='76;79;105'`, `red='210;15;57'`, `peach='254;100;11'`, `yellow='223;142;29'`,
  `green='64;160;43'`, `sapphire='32;159;181'`, `mauve='136;57;239'`, `lavender='114;135;253'`.

## Источник данных

Claude Code передаёт statusline-команде JSON в stdin. Лимиты подписки лежат в:

```json
"rate_limits": {
  "five_hour":  { "used_percentage": 12.5, "resets_at": 1786000000 },
  "seven_day":  { "used_percentage": 63.1, "resets_at": 1786400000 }
}
```

Блок появляется только у подписчиков и только после первого ответа от API. Полную схему
полей показывает `/statusline` внутри Claude Code.
